# Security policy

Only the Odoo 20 development line is currently targeted. This is a development
preview without a production support commitment.

Report vulnerabilities privately to dev@ronaldtorrez.com. Include reproduction
steps with synthetic records and affected versions. Do not publish credentials,
customer data or an exploit in a public issue before coordinating disclosure.

The addon must not expose stock in unauthorized companies. Browser checks are
advisory; enforcement must remain on the server. External payment charges cannot
be rolled back by a database transaction.
